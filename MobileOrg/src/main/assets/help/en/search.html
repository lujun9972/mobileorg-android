Search

Entry

Open search via the magnifying-glass icon in the main menu, then type a keyword to query. The search covers node headings across all synced org files.

Usage Examples

  • Type a fragment when you don't remember the full heading: want to find 2026 Annual Budget Review but only remember "budget"? Type budget to hit every node whose heading contains "budget" — no need to type the full title.
  • Type a keyword directly: enter meeting to hit Weekly meeting notes, Project kickoff meeting, and every other node whose heading contains the keyword; tap one to open it.
  • English keywords are case-insensitive: typing email matches Email and EmailServer.
  • Trying to find all pending tasks (common misconception): typing todo matches nodes that contain the word TODO in the heading, not unfinished tasks. To see your TODOs, use the TODO category item at the top of the main screen, or use Agenda by state.
  • Cannot search body text or tags (common misconception): search matches node headings only; body content and tags are not included. To find by tag, use the tag filter on the main screen (supports AND/OR combinations); to find by date, use Agenda.

Matching Rules & Edge Cases

  • Only node headings (heading text) are searched; body text (payload), tags, and file names are not included
  • Substring matching: a node matches if the keyword appears anywhere in the heading, e.g. entering meeting matches Weekly meeting notes
  • English keywords are case-insensitive: todo and TODO are equivalent
  • There are no operators, regular expressions, or prefix syntax — whatever you type is matched as a literal substring
  • Leading and trailing spaces are stripped automatically: typing meeting searches for meeting
  • % and _ act as wildcards: typing 100% effectively searches for 100; typing % alone matches every node; there is no way to escape these two characters literally

Interacting with Results

Results are shown as a list; tapping one opens the corresponding node. When nothing matches, the title bar shows a no-results notice.
