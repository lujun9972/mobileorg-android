## 代码事实依据（内容必须如实反映）

- `SearchActivity.doSearch()`：`"%" + query.trim() + "%"` 拼 LIKE 模式 → 前后空格自动忽略。
- `OrgFileRepository.search()`：`NAME LIKE ?`——仅匹配节点标题（name 列），payload/标签/文件名不参与；无运算符/正则/前缀语法。
- SQLite `LIKE` 对 ASCII 大小写不敏感。
- `%` 与 `_` 在 LIKE 模式中是通配符（`_` 匹配任意单个字符、`%` 匹配任意字符串），无转义机制：输入 `100%` 实际按 `100` 匹配（末尾 `%` 成通配符）；单独输入 `%` 命中所有节点。
- 无结果时 `setTitle("No results found for ...")`（标题栏提示）。
- 结果列表复用 OutlineListView/OutlineAdapter，点击进入对应节点。
- 主界面 outline 列表顶部有 2 个固定 header 项（TODO、Agenda）——TODO 项可查看所有待办节点，是不搜 `todo` 字样的正确替代。

1. **记不清完整标题时输入片段**：想找 `2026 年度预算评审` 但只记得「预算」→ 输入 `预算` → 命中所有标题含「预算」的节点（子串匹配的核心价值）。

3. **英文关键词不区分大小写**：输入 `email` → 命中 `Email`、`EmailServer`。
4. **想找所有待办任务（常见误解）**：输入 `todo` 命中的是**标题里含 TODO 字样**的节点，不是未完成任务；查看待办的正确做法是主界面顶部的 TODO 分类项，或按状态用 Agenda。
