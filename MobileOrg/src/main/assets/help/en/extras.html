More Features

Undo

Use the "Undo" item in the main menu to undo the last batch of local changes before sync (LIFO order). Before undoing, you'll see a description summary (e.g., "Edit title 'xxx'"), and after undo the nodes revert to their pre-modification state. Undo is not possible if the node has been deleted remotely.

Share Subtree

Long-press a node or select "Share" from the node view page menu to export the full subtree text (including child nodes). Text is sent via the system share sheet, suitable for copying to other apps or note-taking tools. Oversized subtrees are truncated to 400,000 characters to avoid system limits.

Theme

Select a UI theme in Settings → Theme: Dark (dark mode, default), Light (light mode), or Monochrome (single color). The theme controls the entire app's appearance, including ActionBar, list items, and TODO state colors. Theme changes take effect immediately.
