同步配置

同步方式

MobileOrg 支持三种同步方式：

方式所需配置适用场景
WebDAVURL、用户名、密码支持 WebDAV 的云存储（如 Nextcloud、ownCloud）或 HTTP 服务器
SSH主机、端口、用户名、密码或密钥、远程路径通过 SSH/SFTP 访问的远程服务器（如 VPS、NAS）
SD 卡本地目录路径在同一设备上通过其他 app 或文件管理器管理 org 文件

服务端准备

服务端只需一个可读写的目录，内含：index.org（必需）、参与同步的 org 文件、checksums.dat（增量比对用）。

Emacs 工作流（标准）：将 org-mobile-directory 指向该目录，执行 org-mobile-push 自动生成 index.org 与 checksums.dat。

手写最小 index.org：无 Emacs 时手写即可：

#+TODO: TODO DOING | DONE CANCELED
* 文件清单
[[file:home.org][Home]]
[[file:work.org][Work]]

三种同步方式的服务端要点：

  • WebDAV：任何支持读写（GET/PUT）的 WebDAV 服务（Nextcloud、ownCloud 或自建）
  • SSH：服务器开启 SFTP 可读写即可（密码或密钥认证）
  • SD 卡：本地目录即可（其他 app 或文件管理器放入文件）

配置向导

首次配置请进入 设置 → Actions → Setup Wizard。选择同步方式后填写各字段：

  • WebDAV：URL 需包含完整的 index.org 路径（如 https://cloud.example.com/mobileorg/index.org），向导会自动提取目录路径用于其他文件
  • SSH：远程路径也需指向 index.org（如 /home/user/org/index.org）；端口默认 22；可用密码或 SSH 私钥认证（点击按钮选择密钥文件）
  • SD 卡：浏览本地存储，选择 org 文件所在目录（需包含 index.org）

配置完成后点击"测试连接"验证，再点击"完成"自动执行首次同步。

同步的工作原理

MobileOrg 采用双向同步机制：

  1. 拉取：下载服务器的 index.org 和 checksums.dat，对比本地与远端校验和，仅下载变更文件。从服务器 index.org 移除的文件会在本地同步后删除。
  2. 解析：下载的 org 文件由 OrgFileParser 解析入库，节点可通过 ContentProvider 访问。
  3. 推送：本地 capture 和编辑进入 Edits 队列，下次同步时合并到 mobileorg.org 并上传到服务器。上传后本地队列清空。

完整机制与文件格式详见 工作原理。

配置导入导出

进入 设置 → Actions → Export Sync Configuration 可将当前同步配置导出为 JSON 文件，通过系统文件选择器保存到任意位置（推荐云盘）。重装 app 后使用 Import Sync Configuration 选择该文件即可恢复配置，无需重新填写。

常见问题

  • 自签名证书提示：使用 HTTPS 且服务器自签名证书变更时，同步会弹出 CertificateConflict 界面，显示新旧证书哈希。选择"接受"更新证书存储，"拒绝"则中止同步。
  • 同步失败：检查通知栏的错误信息。常见原因包括 URL/路径错误、用户名密码错误、网络未连接或服务器权限问题。
