提醒系统

自动提醒

MobileOrg 自动扫描所有节点的 DEADLINE 和 SCHEDULED 日期，并在到期前发送通知。提醒在同步后和开机时自动注册；只有 TODO 状态为激活的节点才会触发提醒。

配置提醒

在设置 → Reminders 中开启提醒功能，可配置提前量（DEADLINE 默认提前3天，SCHEDULED 默认当天）和每日总览时间（每天固定时间汇总当日到期事项）。每日总览通知分类显示"今日计划"和"临近截止"条目。

Android 12+ 精确闹钟限制

Android 12（API 31）起，精确闹钟权限是特殊权限——需要在系统设置中手动授予。若未授权，提醒会退化为不精确模式（10分钟窗口），可能延迟数分钟触发。首次使用建议在系统设置中授予 SCHEDULE_EXACT_ALARM 权限。

同步到系统日历

除了应用内通知，还可以把带 DEADLINE 或 SCHEDULED 的节点写入 Android 系统日历，在系统日历应用或小部件中统一查看。在 设置 → 日历 中开启「日历同步」并选择目标日历；首次开启会请求日历读写权限。可选配置：为日历条目添加提醒（含提前分钟数）、显示已完成条目、显示过去事件、显示习惯（habits）。

日历条目在每次同步完成后自动更新，开机后也会刷新一次。修改日历设置后若想立即全量刷新，可在 设置 → Actions → Clear Database 清空数据库后重新同步。

高级选项「吸收日历条目」（实验性）：把日历中非 MobileOrg 创建的条目并入 capture 文件，可配合自动删除原条目使用。
