搜索

入口

通过主菜单的放大镜图标进入搜索，输入关键词即可查询。搜索范围是所有已同步 org 文件的节点标题。

场景案例

  • 记不清完整标题时输入片段：想找 2026 年度预算评审 但只记得「预算」？输入 预算 即可命中所有标题含「预算」的节点——不需要输入完整标题。
  • 中文关键词直接搜：输入 会议，命中 周会会议纪要、项目启动会议 等所有标题含该关键词的节点，点选进入。
  • 英文关键词不区分大小写：输入 email 可命中 Email、EmailServer。
  • 想找所有待办任务（常见误解）：输入 todo 命中的是标题里含 TODO 字样的节点，不是未完成任务。查看待办请用主界面顶部的 TODO 分类项，或按状态用 Agenda。
  • 搜不到正文/标签（常见误解）：搜索只匹配节点标题，正文内容与标签不参与。按标签找请用主界面标签过滤（支持 AND/OR 组合），按日期找请用 Agenda。

匹配规则与边界

  • 只搜索节点标题（heading 文本）；正文（payload）、标签、文件名均不参与搜索
  • 子串匹配：标题任意位置包含关键词即命中，例如输入 会议 可命中 周会会议纪要
  • 英文关键词大小写不敏感：todo 与 TODO 等价
  • 没有运算符、正则或前缀语法——输入什么就按字面子串匹配
  • 前后空格自动忽略：输入 会议 按 会议 搜索
  • % 与 _ 按字面匹配：输入 100% 就搜字面的 100%，a_b 就搜字面的 a_b，不会被当作通配符

结果交互

搜索结果以列表形式展示，点击任一结果进入对应节点。无结果时标题栏会显示无结果提示。

节点的基本浏览与操作见 Outline 基本操作。
