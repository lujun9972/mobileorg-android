Quick Start

1. Setup Sync

MobileOrg supports WebDAV, SSH, and local storage synchronization. Open Settings, tap Actions → Setup Wizard to configure.

For detailed setup instructions, see Sync Settings.

2. First Sync

After configuration, tap the sync icon in the top-right corner of the main screen to start your first sync. Once completed, your org files will appear in the list.

3. Daily Usage

  • Tap the + button to quickly capture new ideas.
  • Long-press a node to open the action menu: edit, delete, start pomodoro, share node content, etc.
  • Check the checkbox before a node to mark it as done.
  • Tap a node to view its full content.
