Outline Basics

Main Interface

The main interface displays your org file list. At the top of the list are two fixed items: TODO and Agenda. Tapping them shows task summaries and schedule views respectively. The file list displays nodes hierarchically—tap a node to enter its subtree and view child nodes, then use the back button to return to the previous level. The interface supports filtering by tags, with available tags shown at the top for selection.

Long-Press Menu

Long-pressing any node opens a context menu that automatically adjusts based on the node type:

  • Editable nodes: Provide options for editing, adding child nodes, deleting, Clock In (time tracking), Pomodoro timer, voice recording, archiving, and sharing
  • Read-only nodes: Only offer viewing and sharing functions
  • File nodes: Support editing, adding child nodes, file deletion, recovery, and sharing, with additional Clock In, Pomodoro timer, and voice recording features
  • Agenda file nodes: Offer viewing, editing, file deletion, recovery, and sharing options; unlike regular file nodes, they lack Clock In, Pomodoro timer, voice recording, and similar items

Capturing Ideas

Use the "Capture" option from the main menu or quick capture feature to quickly record thoughts. The system opens the editor to create a new entry, with the option to add it as a child node of the current node. Capture is ideal for quickly capturing ideas on the go, to be organized into formal org files later.

Editor

The editor uses a tabbed design with the following sections:

  • Heading: Edit node title, TODO state, and priority
  • Dates: Set DEADLINE (due date) and SCHEDULED (planned time)
  • Tags: Add or modify node tags
  • Payload: Edit detailed node content, supporting org syntax including lists, checkboxes, links, and other formats

Agenda & Search

The Agenda item opens the agenda list, aggregating tasks by file, tag, TODO state, date, and other criteria. Use Create in the menu to add a custom agenda; long-press an existing agenda to edit (Configure) or remove (Remove) it. The search function is accessed via the magnifying glass icon in the main menu, matching node titles by keyword substring—see Search for details.

Display Settings

  • Child nodes to display (Settings → Interface → View): How many levels of child nodes to show when viewing a node. The default of 0 shows only the current node's body; increase it to include child node content as well.
  • Combine block agendas (Settings → Synchronization → Advanced): Merges block agendas from the agenda file into a single node with separators. Requires resyncing the agenda file to take effect.

Home Screen Widgets

The app provides two home screen widgets: Outline Widget displays an agenda overview—tap to quickly create a new entry (opening the capture editor); Capture Widget focuses on quick recording—tap to directly enter the capture editor without opening the main interface. Widgets support customizing displayed content for convenient viewing and recording from your home screen.
