快速上手

1. 配置同步

MobileOrg 支持 WebDAV、SSH 和本地存储三种同步方式。打开设置，点击 Actions → Setup Wizard 即可完成配置。

详细配置步骤请参考 同步设置。

2. 首次同步

配置完成后，点击主界面右上角的同步图标开始首次同步。同步完成后，您的 org 文件将出现在列表中。

3. 日常使用

  • 点击右下角的 + 按钮快速 capture 新想法。
  • 长按节点弹出操作菜单：编辑、删除、启动番茄钟、分享节点内容等。
  • 勾选节点前的 checkbox 完成任务。
  • 点击节点查看完整内容。
